## 🎯 Problem Statement

### User Scenario (French)
> "J'ai un trade sur avax actuellement il m'a fait un roi de 15% mais ils semble stagner et le momentum arrêter mais je suis en trail mais il s'active pas encore. Pour le momentum semble s'épuiser. Est ce que je dois le laisser ? Est ce que sa peut reprendre? Dois ont appliquer une logique de stagnant trade aussi pour les trade réussi qui bloque ou je dois attendre le trail reach ?"

### Translation & Analysis
User has an AVAX trade with:
- 15% ROI (75% ROE with 5x leverage)
- Momentum appears exhausted/stopped
- Trailing stop is enabled but hasn't triggered yet
- Questions:
  1. Should they let it run?
  2. Can it resume?
  3. Should we apply stagnant trade logic to successful trades that are stuck?
  4. Should they wait for trailing to reach?

### Root Cause
**Gap in existing system**: 
- V5.34 stagnant trade logic only applies BEFORE trailing activates (maxPnlPct < 0.8%)
- No mechanism for trades that reach significant profit (>5%) but then momentum exhausts while trailing is active but not triggered

## 💡 Solution: V5.40 Momentum Exhaustion Detection

### Concept
Detect momentum exhaustion on already successful trades and **tighten the trailing stop** (don't exit immediately).

### When It Triggers
All conditions must be met:
1. ✅ Position profit > 5% ROI (significant success worth protecting)
2. ✅ Trailing stop already active (this is a late-stage issue)
3. ✅ ROC5 < 0.003 (0.3% in decimal - very weak short-term momentum)
4. ✅ ROC10 < 0.005 (0.5% in decimal - weakening medium-term trend)
5. ⚪ Optional: Volume < 0.8x average (currently disabled)

### Action Taken
- **Before**: Trailing distance = 0.5-0.8% (adaptive based on volatility)
- **After Detection**: Trailing distance = 0.3% (tightened)
- **Effect**: Trailing stop moves closer to current price, protecting more profit
- **No Immediate Exit**: Trade continues, can still run if momentum resumes

### Example Calculation
```
Entry: $30 AVAX LONG
Current: $34.50 (15% profit)
High Water Mark: $34.50

Normal Trailing:
- Distance: 0.5% (medium volatility)
- Stop: $34.50 * (1 - 0.005) = $34.33

After Momentum Exhaustion Detection:
- Distance: 0.3% (tightened)
- Stop: $34.50 * (1 - 0.003) = $34.40

Improvement: $34.40 - $34.33 = $0.07 additional protection
Percentage: 0.2% more profit protected
```

#### 2. `momentumSimple.ts` - Detection Logic
Location: `shouldExitPosition()` function, within `if (trailingIsActive)` block

```typescript
// V5.40: MOMENTUM EXHAUSTION - Tighten trailing on successful but stagnating trades
let momentumExhausted = false;

if (MomentumConfig.EXIT.MOMENTUM_EXHAUSTION_ENABLED && 
    pnlPct >= MomentumConfig.EXIT.MOMENTUM_EXHAUSTION_MIN_PROFIT_PCT &&
    candles && candles.length >= 11) {
  
  const roc5 = calcROC(closes, 5);
  const roc10 = calcROC(closes, 10);
  
  // For LONG: momentum exhausted if ROC5 and ROC10 near zero or negative
  const roc5Weak = Math.abs(roc5) < MomentumConfig.EXIT.MOMENTUM_EXHAUSTION_MAX_ROC5_PCT;
  const roc10Weak = Math.abs(roc10) < MomentumConfig.EXIT.MOMENTUM_EXHAUSTION_MAX_ROC10_PCT;
  
  momentumExhausted = roc5Weak && roc10Weak;
  
  if (momentumExhausted) {
    trailingDistance = MomentumConfig.EXIT.MOMENTUM_EXHAUSTION_TIGHTEN_DISTANCE_PCT;
  }
}
```

#### 3. `momentumSimple.ts` - Interface Update
```typescript
export interface ExitSignal {
  // ... existing fields
  momentumExhausted?: boolean;  // V5.40: Flag for momentum exhaustion
  trailingDistancePct?: number;  // V5.40: Current trailing distance
}
```

### Key Design Decisions

1. **Decimal vs Percentage Format**
   - `calcROC()` returns decimals (0.003 = 0.3%)
   - Config values use decimals for consistency
   - Comments clarify: "0.003 decimal (0.3%)"

2. **Volume Check Optional**
   - `REQUIRE_VOLUME_CHECK: false` by default
   - Momentum indicators alone are sufficient
   - Can be enabled for additional confirmation if needed

3. **Safe Volume Calculation**
   - Uses `volumeSlice.length` for division (not hardcoded 20)
   - Handles cases with < 20 candles gracefully
   - Guards against division by zero

4. **Placement in Logic Flow**
   - Checked AFTER stagnant trade logic
   - Applied WITHIN trailing active block
   - Modifies `trailingDistance` before stop calculation
   - Complements, doesn't replace existing logic
