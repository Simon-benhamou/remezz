## 🔧 Changes Implemented

### 1. ✅ CRITICAL FIX: State Persistence for Restart Safety

**Problem Found**: Position state (stagnant trade, maxPnlPct, trailing activation) was not persisted to database, causing loss of state on agent restart.

**Fix Applied**:
- **File**: `backend/prisma/schema.prisma`
- **Changes**:
  ```prisma
  model Position {
    // Added V5.34 state persistence fields:
    maxPnlPct       Float?   // Max PnL % reached (for stagnant trigger)
    stagnantState   Json?    // {triggered, triggeredAt, confirmed, cancelled, obsPeakPct}
    trailingActive  Boolean  @default(false)
    highWaterMark   Float?   // Highest price for LONG trailing
    lowWaterMark    Float?   // Lowest price for SHORT trailing
    entryTime       BigInt?  // Unix timestamp (ms)
    marginUsd       Float?   // Margin allocated (USD)
  }
  ```

**Migration File Created**: `backend/prisma/migrations/20260101_add_position_state_tracking.sql`

**To Apply**:
```bash
cd backend
npx prisma migrate dev --name add_position_state_tracking
npx prisma generate
```

**Impact**:
- ✅ Stagnant trade logic survives restarts
- ✅ Trailing stop activation persists
- ✅ Critical for V5.34 3-phase state machine

### 3. ✅ OPTIMIZATION: Momentum Reversal 2-Candle Confirmation

**Rationale**: Reduce false exits from single noisy candles showing temporary momentum flip

**Files Modified**:
- `backend/src/strategies/momentumSimple.ts` (lines 1333-1363)
- `backend/src/services/backtestService.ts` (lines 1011-1034)

**Change**:
```typescript
// Before V5.35 (1-candle):
if (candles.length >= 6) {
  const roc5 = calcROC(closes, 5);
  if (position.side === 'long' && roc5 < -0.015) {
    exit('momentum_reversal');
  }
}

// After V5.35 (2-candle confirmation):
if (candles.length >= 7) {
  const roc5Current = calcROC(closes, 5);
  const roc5Previous = calcROC(closes.slice(0, -1), 5);

  // Require BOTH candles below -1.5%
  if (position.side === 'long' && roc5Previous < -0.015 && roc5Current < -0.015) {
    exit('momentum_reversal');
  }
}
```

**Expected Impact**:
- ✅ Fewer momentum reversal exits (filters noise)
- ✅ Reduced loss count from false exits
- ✅ Higher win rate (fewer premature exits)
- ⚠️ May delay exit on genuine reversals by 15min (1 candle)

**Backtest Validation Needed**: Compare momentum reversal exit count and outcome
