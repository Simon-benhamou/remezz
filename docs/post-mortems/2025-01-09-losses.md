## Cross-Trade Themes
- **Momentum confirmation drift**: ADX consistently dropped below 20 before exits, yet the agent waited for stops. Mitigation: lower the ADX floor for active trades and exit when CMF + RSI both disagree with bias.
- **Liquidity guard enforcement**: Warnings on BNB and SOL should block entries instead of logging advisory messages. Mitigation: promote liquidity guard to a hard gate once depth ratios fall below 0.5.
- **Circuit breaker latency**: Breaker only enforced after the ADA exit. Mitigation: transition breaker state to `armed` upon penultimate loss and prevent new entries until cooldown lapses.
